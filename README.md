# CEPIMATE – Protótipo do Site

Protótipo estático (HTML/CSS) do site do **CEPIMATE – Centro de Pesquisa e Inovação em Materiais e Estruturas**, do IFSP Campus São João da Boa Vista, construído com o template da Identidade Digital do Governo Federal.

Não é preciso instalar nada: o projeto é HTML puro e abre direto no navegador.

## Como abrir

Escolha **uma** das opções abaixo.

### Opção 1 – Pelo link (mais rápido)

Acesse o endereço abaixo no navegador:

> **https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/**

*(Substituir pelo link real do GitHub Pages antes de enviar.)*

### Opção 2 – Baixando o ZIP (sem instalar nada)

1. Abra a página do repositório no GitHub:
   **https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO**
2. Clique no botão verde **Code** e depois em **Download ZIP**.
3. Localize o arquivo baixado, clique com o botão direito e escolha **Extrair tudo…** (Windows) ou dê dois cliques (macOS).
4. Abra a pasta extraída e dê dois cliques em **`index.html`**. A página abrirá no navegador.
5. Use o menu do site para navegar entre as páginas.

> **Importante:** mantenha a pasta inteira junta. As pastas `img`, `js` e `Identidade Digital do Governo` carregam o visual do site. Se o `index.html` for movido para fora da pasta, a página abrirá sem estilo.

### Opção 3 – Clonando com Git

```bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
cd NOME-DO-REPOSITORIO
```

Depois abra o arquivo `index.html` no navegador (clique duplo, ou arraste o arquivo para a janela do navegador).

### Opção 4 – Pelo VS Code, com Live Server (opcional)

1. Abra a pasta do projeto no VS Code (**File → Open Folder**).
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.
4. O site abre em `http://127.0.0.1:5500` e atualiza sozinho a cada alteração salva.

## Se algo não aparecer direito

- **Página sem cores/estilo ou sem imagens:** a pasta foi movida ou extraída pela metade. Extraia o ZIP completo e abra o `index.html` de dentro da pasta extraída.
- **Navegador mostra o código em vez da página:** abra o arquivo com o navegador (botão direito → *Abrir com* → Chrome, Edge ou Firefox).
- **Link do GitHub dá erro 404:** o repositório pode estar privado. Peça à autora para adicionar seu usuário como colaborador.
- **Link do GitHub Pages ainda não abre:** após a ativação, pode levar de 1 a 2 minutos para ficar no ar.
